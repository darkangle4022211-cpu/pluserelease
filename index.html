Core System Architecture

Engineered to bypass GitHub API rate limits.

Traditional app updaters query the GitHub REST API, exhausting the 60 requests/hour IP limit within minutes. PulseRelease routes update queries through direct raw manifests, providing unlimited client polls.

Direct Manifest Delivery

Clients fetch a static, pre-compiled JSON manifest directly through global CDNs, completely bypassing GitHub's unauthenticated REST API rate ceilings.

Automated SHA-256 Hashing

Every dropped artifact is hashed on-the-fly. Clients cryptographically verify binary integrity before executing updates, preventing corrupted payloads.

Central Multi-App Registry

Orchestrate updates across your entire software lineup—from HyperDrain to Pulsar Audio and AeroPlayer—from a single unified release dashboard.

Zero-Dependency Client SDKs

Drop-in companion scripts for Python, Shell, Kotlin/Android, Tauri, and C++ with automatic version comparison and silent update handoffs.

import urllib.request, json, os, hashlib

def check_for_updates(manifest_url, current_version):
    req = urllib.request.Request(manifest_url, headers={'User-Agent': 'PulseRelease-Client/1.0'})
    with urllib.request.urlopen(req) as resp:
        if resp.status != 200:
            return None
        manifest = json.loads(resp.read().decode('utf-8'))
        remote_ver = manifest.get('version', '')
        if remote_ver != current_version:
            print(f"[+] Update Available: v{current_version} -> v{remote_ver}")
            print(f"[*] Changelog: {manifest.get('changelog', '')}")
            return manifest
    return None

def verify_and_download(url, target_path, expected_sha256):
    urllib.request.urlretrieve(url, target_path)
    with open(target_path, 'rb') as f:
        computed = hashlib.sha256(f.read()).hexdigest()
    if computed != expected_sha256:
        os.remove(target_path)
        raise ValueError("SHA-256 checksum mismatch!")
    print("[+] Download verified successfully.")
